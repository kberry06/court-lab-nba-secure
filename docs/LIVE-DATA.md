# Schedule, roster and probability workflow

Open NBA schedule and choose a Sydney date. Saved projections appear immediately; missing or outdated model versions are regenerated in the background. Refresh prediction reloads current rosters, published injury listings, recent completed team games and player histories. Refreshes are cached on the existing persistent disk. No paid NBA subscription is required.

These endpoints are also documented in the open-source [hoopR project](https://github.com/sportsdataverse/hoopR/blob/master/R/espn_nba_data.R) and its [team helpers](https://github.com/sportsdataverse/hoopR/blob/master/R/espn_basketball_team_helpers.R). Open-source tooling does not make ESPN's underlying data openly licensed. This is a private research integration, with no redistribution licence claimed or guaranteed service-level agreement. HTTP access denials stop retrieval; no proxies, browser impersonation or protection bypasses are used. Provider failure retains saved data and displays an error.

Current roster membership comes from the current roster endpoint, not historical box scores. IDs use the `espn:game:`, `espn:team:` and `espn:player:` namespaces. Times display in Australia/Sydney. Data collection timestamps are separate from historical game dates. Injuries are listings, not verified starting lineups. Out/doubtful/questionable/probable availability values and the scoring/assist-based player-impact estimate are explicit heuristic assumptions that the owner can adjust.

Complete bundles update historically fitted opponent-adjusted team states from current-season results for all 30 teams, using a shared six-hour cache. The trained game classifier includes rest and back-to-backs; totals and game dispersion are also fitted. Player history uses up to 20 completed regular-season appearances, following athlete IDs across trades and deduplicating games before counting coverage. The selected recency/shrinkage estimator supplies conditional minutes and rates. Players with fewer than three appearances keep conservative priors, and roster minutes are normalized to 240 before injury sampling. Historical results inside the last 24 hours are embargoed. Player availability, final point allocation, covariance and prop tails remain unvalidated. Incomplete bundles retain a labelled recent-score game fallback.

The first prediction saved before each real tip-off is frozen immutably in SQLite, both for the original event forecast and separately for each model version. Later schedule refreshes settle those forecasts from final scores. Re-running a matchup cannot replace its model's first evaluation record. `/api/accuracy` reports the new model's settled count; prospective validation remains pending. The original frozen audit can run with `{"live":true}` once enough settled records exist; that legacy audit may span model versions and must not be presented as the new model's exclusive performance.

The simulation produces projected scores, both teams' win probabilities, model fair odds, total/margin distributions, player means/ranges and conditional-on-playing milestone probabilities (20+ points, 8+ rebounds, 5+ assists). Those probabilities are model estimates, not demonstrated NBA accuracy.

The owner approved the existing Odds API subscription for NBA on 18 October 2026. `ODDS_PROVIDER=the-odds-api` and `ODDS_FEED_APPROVED=true` enable server-side use of the existing Render `ODDS_API_KEY`; no key is copied into source or browser storage. Sportsbet game prices and per-event player markets are queried only through documented aggregator endpoints, cached for 15 minutes to bound credit use. Empty props are reported as unavailable, not synthesized. Sportsbet-specific settlement and display rights remain governed by the owner's provider agreement.

Exact unique team names plus tip-off time map events; exact unique full player names map props. Ambiguous names, unmatched events and reschedules are quarantined. Canonical IDs and mappings persist. Prices retain provider observation times. The comparison shows price, model probability/fair odds, two-sided no-vig bookmaker probability where available, edge, expected return and freshness. Manual entry remains available.

Public schedules, roster/history snapshots, stored runs and odds survive deployments on the existing disk. No extra Render service or paid NBA feed was added.
